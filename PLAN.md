# Метод встраивания

Используется 16-битный PCM.

Один сэмпл занимает:

```text
2 байта
```

Мы прячем один бит полезной нагрузки в младший бит каждого сэмпла.

Ёмкость:

```text
capacity_bytes = pcm_bytes / 16
```

Пояснение:

```text
pcm_bytes / 2          = количество сэмплов
количество сэмплов / 8 = количество байт полезной нагрузки
итого:
pcm_bytes / 16
```

Пример:

```text
44.1 kHz
16 bit
stereo
```

Скрытая ёмкость:

```text
≈ 10.8 КБ в секунду
```

Для трека длиной 3 минуты:

```text
≈ 1.9 МБ текста
```

# Ограничения варианта A

Текущий метод хорошо подходит для:

```text
WAV / PCM
```

и других несжатых / безпотерьных аудиоформатов.

Он не рассчитан на сохранение данных после:

- перекодирования в формат с потерями;
- сохранения в MP3;
- изменения громкости;
- нормализации;
- обрезки;
- изменения частоты дискретизации;
- шумоподавления;
- эффектов;
- повторного сжатия.

Это нужно явно указывать пользователю.

# Отношение к MP3

В текущей версии используется подход:

```text
MP3 → WAV → SoundBox → WAV
```

Пример:

```bash
ffmpeg -i input.mp3 -c:a pcm_s16le -ar 44100 -ac 2 input.wav
```

Прямой режим вида:

```text
LSB → MP3
```

не реализуется, потому что после сжатия с потерями скрытые данные почти гарантированно теряются.

В будущем можно отдельно рассмотреть:

```text
Вариант B: размещение зашифрованного пакета в метаданных аудиофайла
```

Например, через приватные поля метаданных.  
Но это уже не классическое скрытие в самом аудио сигнале.

## Направления исследования

### 1. Spread spectrum

Идея:

- полезная нагрузка распределяется по широкой части аудиосигнала;
- используется псевдослучайная последовательность;
- извлечение возможно при наличии ключа.

Плюсы:

- лучшая устойчивость к шуму и сжатию;
- сложнее обнаружить без ключа.

Минусы:

- ниже ёмкость;
- сложнее реализация;
- нужны тесты на качество звука.

---

### 2. Phase coding

Идея:

- информация прячется в фазовых характеристиках сегментов сигнала.

Плюсы:

- потенциально хорошая устойчивость к некоторым преобразованиям;
- может быть менее заметной на слух.

Минусы:

- сложная работа с фазой;
- возможны артефакты;
- сложности синхронизации и извлечения.

---

### 3. Echo hiding

Идея:

- информация кодируется параметрами искусственного эха:
  - задержка;
  - амплитуда;
  - время затухания.

Плюсы:

- концептуально простой метод;
- может быть устойчив к некоторым обработкам.

Минусы:

- низкая ёмкость;
- заметность при неправильных параметрах;
- ограниченная применимость для разных типов аудио.

---

### 4. DCT/DWT-based methods

Идея:

- аудио разбивается на блоки;
- применяется дискретное косинусное или вейвлет-преобразование;
- данные прячутся в коэффициентах преобразования;
- возможно использование quantization index modulation.

Плюсы:

- ближе к алгоритмам, устойчивым к сжатию;
- можно выбирать частотные области с меньшей чувствительностью;
- хорошо подходит для исследований.

Минусы:

- самая сложная реализация;
- нужно тщательно подбирать параметры;
- необходимы тесты после кодирования в формат с потерями.


