# SoundBox / Research — Вариант C

Исследовательский модуль устойчивой аудио-стеганографии.

Не является частью продукта. Не зависит от GUI, CLI и AudioEngine.

## Цель

Сравнить физические методы скрытия бит в аудио по устойчивости
к шуму, изменению громкости, фильтрации и потере синхронизации.

Криптография в этом модуле намеренно отсутствует.
Здесь измеряется канал, а не защита сообщения.

## Модель

- все методы встраивают 1 бит в блок одинаковой длины;
- поверх блока работает повторный код с голосованием;
- сообщение кадрируется: 16 бит длины + payload;
- перед данными встраивается sample-level преамбула для синхронизации;
- метрики: BER и факт точного восстановления payload.

## Синхронизация

Раньше синхронизация была блочной (`SyncStegoChannel`): заголовок
искался только по границам блоков. Любой сдвиг на нецелое число
блоков (crop/pad на 131, 137, 149 отсчётов) полностью ломал чтение.

Сейчас используется `SampleSyncPreamble` — широкополосная ПСП,
встроенная аддитивно в начало сигнала. При приёме точный сдвиг
восстанавливается нормированной взаимной корреляцией. Это даёт:

- устойчивость к crop и pad на произвольное число отсчётов
  (пока сохранилось ≥ 50% преамбулы);
- естественную основу для будущей оценки gain через амплитуду
  корреляционного пика;
- готовую базу для MP3 roundtrip, где кодек даёт sample-level
  задержку порядка 576–1152 отсчётов.

Параметры по умолчанию: длина 1024 отсчёта (4 блока при
`blockSize = 256`), амплитуда 0.10, стойкость к шуму — до
`noise20` включительно.

## Методы

- spread-spectrum — корреляция с балансной ПСП;
- phase-coding — фаза пилотного тона 0 / PI;
- echo-hiding — выбор одной из двух задержек эха;
- dct-qim — QIM в коэффициенте DCT-II;
- haar-qim — QIM в коэффициенте вейвлета Хаара.

## Запуск

./gradlew :research:test
./gradlew :research:run

## Текущие результаты

Сводка по 3 сигналам (tone / noise / speech-like) × 13 атак:

| метод | точно восстановлено |
|---|---|
| spread-spectrum | 34 / 39 |
| phase-coding | 34 / 39 |
| dct-qim | 26 / 39 |
| haar-qim | 26 / 39 |
| echo-hiding | 11 / 39 |

Embedding SNR: 6.8–17.1 dB в зависимости от сигнала.

Устойчиво проходят: `none`, `gain*`, `noise30`, `noise20`,
`crop131`, `crop137`, `crop149`, `pad137`, `pad512`, `crop512`.

Стабильно ломаются:

- `lowpass8` / `lp16` на узкополосных сигналах (tone, speech-like):
  фильтр убивает широкополосную преамбулу и сам канал, а не только
  синхронизацию. На белом шуме `lowpass8` проходит;
- `gain*` на `dct-qim` / `haar-qim`: фиксированный шаг квантования
  не масштабируется вместе с громкостью;
- тональный и speech-like для `echo-hiding`: собственная
  периодичность сигнала маскирует эхо.

## Сознательные ограничения

- нет криптографии;
- нет MP3-атаки;
- DCT реализован напрямую, без FFT;
- параметры методов фиксированы и не оптимизированы;
- lowpass на узкополосных сигналах — физический предел
  широкополосного встраивания, а не дефект синхронизации;
- QIM чувствителен к изменению громкости: AGC пока не реализован.
